#   BUG HUNTER
Trò chơi lấy cảm hứng từ những tựa game nổi tiếng như Enter the Gungeon và Bug Hunter sử dụng Three.js.

HƯỚNG DẪN CÀI ĐẶT & CHẠY DỰ ÁN
------------------------------------------------------------
Bước 1: Clone project từ GitHub bằng cách chạy các lệnh sau:
```
git clone https://github.com/ParsleySun159/Computer-Graphics.git
cd Computer-Graphics
```
Bước 2: Chạy lệnh
```
Sử dụng Node.js:
npx http-server .
Hoặc dùng python:
python -m http.server
```
Sau đó truy cập: http://localhost:8000/
